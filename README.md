# 秋秋一中：校长志

一款完全离线运行的静态 HTML 学校经营策略游戏原型。直接打开 `index.html` 即可游玩；浏览器会使用 `localStorage` 自动保存任期。

## 已实现的主循环

- 从 4 位校长中选择一位，并选择 1 / 3 / 5 年任期；选择界面会公开六维能力的实际公式影响与个人特性。
- 从 2022 年 7 月 1 日开始，按天或按周推进；每周恢复行动点、必定触发一项校园事件，每月结算财政。
- 18 个班、420 名在校生（普通班 25 人、精英班 20 人）；数据模块可确定性生成 1,200 名学生与 260 名教师。
- 12 个分级管理岗，可从教师队伍提拔，或先从人才市场签约进入待任库再任命。
- 学生和教职工均有六维属性、星级/层级、特征与雷达图档案；学生档案还显示精确分数、等级、进度条与每项能力的作用。
- 职工满意度、教师满意度、学生满意度、安全度、校长权威与行政效率构成治理反馈。
- 首页改造成可交互的校长办公桌：香香市地图、人事档案、班级花名册、红头文件、财务账本与工作日程分别进入对应功能；关键数值保留明确的下周预计变化和悬停说明。
- 新增学校稳定度：安全、权威、行政效率、三类满意度、领导层岗位支撑、学生情绪与现行政策共同决定，政策页可逐项查看构成。
- 每名学生新增愤怒值。严格管制、频繁考试、教师空缺和低满意度会推高愤怒；谈心、心理减压及宽松制度可降低。高愤怒会拖累日常成长与考试发挥，达到风险线后联考可能交白卷。
- 新增 11 类学校政策、33 个选项，覆盖发型、校服、课间、手机、作息、周末、作业、考试、晚自习、违纪处置和宿舍管理；周末可选择“四周休一天”，每个选项均公开即时及长期效果。
- 新增“秘书建议”：系统以纯读取方式综合资金、师生状态、岗位、政策、设施、预算、考试日程和校长能力，对全部行动进行评分并给出处理入口。
- 新增校长侯鸿杰：“鼓舞人心”消耗 5 点权威，使下一场月考、联考或高考模拟的全体成绩提高 10%；“振奋人心”消耗 10 点权威，使全校学生愤怒降低 5 点。
- 管理人员按岗位适配度持续提供差异化的教学、行政、安全、满意度或成本增益，组织卡片会显示岗位预计贡献。
- 十二个管理岗位均收束为两项核心职责增益，部门与年级岗位的功能区别更加明确。
- 可撤销管理职位、解聘教师或从待任库更换教师，三者具有不同的权威与满意度代价。
- 10×10 香香市连片实力版图；学校影响力精确到两位小数，虚线显示边境渗透进度。
- 首页基础数值显示下周预计增减，月历记录联考、行动、事件与财务日期。
- 校际联考可预约日期、年级、班级和总负责教师，并以入场、发卷、答题、交卷、阅卷动画表现。
- 联考公开显示六项判定；参赛规模占 10%，学生水平占 35%，其余项目合计 55%。
- 联考胜负只推进影响力进度，达到 100% 后才会改变地块归属。
- 18 个独立班级模块区分理科、文科、理科精英与文科精英课程，可查看并单独更换班主任、任课教师。
- 政府拨款、延时费、社会资助、工资、食堂、水电、维护与六个月借款失败规则。
- 可点击的校园平面图包含运动、宿舍、食堂、教学楼、实验楼、信息楼、办公、活动、医务和保卫十个区域；每处可在 0～10 级间升级、降标或变卖停用。
- 玩家可按月调节食堂、设施维护、卫生、安保和资料费预算，投入比例会改变次月支出及对应学校指标。
- 教职工工资由能力、教龄、岗位津贴、全校奖金政策和个人奖金系数组成；支持单人降低奖金及“开源节流”全校降薪。
- 可在班级内撤销或更换班主任、任课教师；主动撤销及解聘教师都会留下真实空缺，持续拖累对应班级的学业、心态和满意度。
- 连续 6 个月负资产、学校影响力低于 3，或任一满意度连续 3 个月低于 10，都会提前结束任期。
- 每年 6 月 1 日至 10 日进入高考冲刺：高三每日模拟考、专项冲刺行动、全市放榜、清北统计、状态奖励，以及升班和新高一招生。
- 学生学业、自律、心态每日按潜力、教师状态、学校政策和年级管理动态变化。
- 其他学校每周会自主教研、宣传、交流或引进教师，并可能主动邀请联考；拒绝正式邀请会损失校长权威。
- 设施升级、全校月考、十类校长行动、十类随机事件、推进过渡效果与本地自动存档。

## 文件结构

- `index.html`：语义化页面骨架和所有游戏界面容器。
- `styles.css`：设计令牌、桌面/移动布局、交互和无障碍样式。
- `data.js`：静态配置、学校/行动/事件，以及确定性人物生成器。
- `campus-event-library.js`：校园事件内容和后续剧情配置。
- `campus-event-expansion.js`：县中专题事件与选择分支的后续配置。
- `campus-event-stories.js`：事件场景补充和批示反馈文案。
- `campus-events.js`：事件筛选、简报抽取、冷却与事件记录。
- `game.js`：单一游戏状态、联考结算器、影响力 AI、存档和视图渲染。
- `assets/campus-hero.png`：为本项目生成的原创校园主视觉。

## 后续扩展约定

新增内容优先写进 `data.js` 的配置数组，不要把数值散落到界面代码。结算遵循：配置读取 → 条件校验 → 纯数值计算 → 状态限幅 → 记账/日志 → 存档 → 重新渲染。治理数值公式详见 `docs/GOVERNANCE_BALANCE.md`。若未来接入真正后端，可保持当前状态对象结构，把 `save/load` 替换为 API 层。

校园事件库共 105 项（含 28 个后续），简报每周抽取三项，最多一项已到期的后续，至少一项单次事件；条件、冷却和未处理事项保存在本地档案。旧存档升级时，每个普通班保留名单中前 25 人、精英班保留前 20 人，其他学校人数一次性调整为原来的 80%。

每项批示结算后会显示实际变化和待跟进提示，未确认的反馈会随存档恢复。现金或行动点不足时，对应选项不可用；提交时也会再次核验。

教师队伍按任教年级、班级及综合能力排序，并列出兼任。教师担任管理岗位时保留原任课任务，其所任科目效率为原来的 90%；班级页面中的各科效率与每日学业成长使用同一计算。人才签约金随综合能力提高。每周其他学校之间也会进行联考，近期结果及边境影响显示在势力版图。

新任期按学科均衡分配教学任务，没有班级任务的教师进入待任人才库；已有管理职务或已排定联考负责人的人员保持在岗。旧存档会在首次载入时，优先用原在职队伍里尚未任课的同科教师分担文化课，并将无班级任务的在职教师转入待任库。这会改变教师工资支出，可先备份存档。组织人事可按姓名、学科和最低综合能力筛选；校长行动按用途分类。

学生成绩当前由学业、自律、心态、教学环境和随机波动共同决定；学校财政以月为最小完整结算周期。首版平衡目标是让普通经营略有压力，但不会在第一个月被迫借款。
