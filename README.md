# 秋秋一中：校长志

离线学校经营游戏。打开 `index.html` 游玩，或访问 https://affogator11.github.io/xz-game/ 。任期自动保存在当前浏览器。

## 本次更新

- 移除地块争夺，改为八校积分联赛。初始积分由实力确定，此后由考试改变。
- 每月20日全市统考，前四加分、后四扣分；每季度末25日全省统考，全校加分；校际联考胜方加分、负方不扣分。加分范围省考＞市考＞校际。
- 保留考生入场、发卷、答题、交卷、阅卷与揭榜动画；其他学校每周自行联考。
- 全校15班、390人：每年级理科普通班2个、文科普通班1个，每班30人；理科、文科清北班各1个，每班20人。
- 班主任仅教本班，其他文化课教师最多教3班；体育、信息各年级独立配置一人。
- 教师队伍按班级紧凑列名，点击查看档案。教师、行政人员保留教学、管理、沟通、成长四项能力，签约费明显降低。
- 行政兼任教师的科目效率为50%；行政效率低会削弱岗位增益。教师与行政人员均可支付补偿、权威后辞退。
- 学习交流先发邀请，7天后答复；接受后选行政人员出访7天，岗位空缺锁定，归校恢复并提升能力。
- 学生保留学业、自律、心态、潜力，另有愤怒、成绩；高分与高学业成长采用边际衰减。
- 删除校园安全度，保障作用并入稳定度与满意度。首页十二项学校状态始终显示，界面数值至多两位小数。
- 独立事件库244项，含66项后续事件，增加状态触发、负面分支与较强影响；每周3项、最多1项后续、至少1项单次事件。
- 简化首页和各分页说明，提供单屏优先布局。长名册、档案和展开内容在各自区域查看。

## 简要操作

选择校长与1／3／5年任期后，在首页查看校情与行动力。人事安排队伍，学生页按年级进入班级，政策页逐项比较制度，财务页安排建设和经费。学校联赛可预约考试、邀请交流；完成周报批示后推进校历。周一恢复行动点，每月1日结算财务，6月1—10日进入高考冲刺。

存档沿用原 `qiu-principal-sim-v1`，升级后直接继续任期。旧420人存档自动重编，超编学生及旧任课等记录归档保留，资金、冷却、批示结果和后续剧情不会清空。存档不会自动跨设备同步。

## 模块

| 文件 | 职责 |
| --- | --- |
| `school-rules.js` | 班型、简化能力、师资约束、存档迁移、积分、成绩衰减、交流 |
| `game.js` | 经营循环、数值结算、任免、考试动画、存档和页面绑定 |
| `game-ui.js` / `compact-ui.css` | 分区、分页、焦点管理与单屏布局 |
| `campus-event-legacy.js` / `campus-event-library.js` / `campus-event-expansion.js` / `campus-event-stories.js` | 保留原事件编号、分支与叙事 |
| `event-content-244.js` / `campus-event-catalog.js` | 新内容与244项唯一事件注册 |
| `campus-event-conditions.js` / `campus-events.js` | 状态检查、概率、冷却与周报调度 |
| `campus-event-results.js` | 资金、情绪、满意度等实际影响执行 |

规则、精确公式与迁移说明见 [联赛与经营规则](docs/COMPETITION_RULES.md)。

## 验证
