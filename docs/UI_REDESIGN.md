# 紧凑界面 · 2026-11-06

首页保留校园、行动力、积分目标、全部十二项状态和可展开校务手记。删去重复口号、页面解释与重复指标。资金、时间推进和导航固定可用。

学校联赛分为积分榜、赛程战报、对手档案、学习交流四页。积分榜保留八行和近况，375×667手机可见全部学校；赛程、历史战报二级切换，避免叠成长列表。历史战报支持类型筛选和分页；对手档案展示对比与交手史，交流页集中追踪进度。

人事按职责切换，教师按年级、班级列名；学生按年级查看五班；政策按分类逐项展开；财务分为建设、预算、账本；校长行动按目的分类。各分页面采用单屏优先布局，长名册和档案在局部区域查看。

`compact-ui.css` 处理单屏结构，最后加载 `readable-ui.css` 统一字体、按钮和联赛布局。所有核心状态始终显示。固定头尾为触摸操作预留空间，数值说明仍可通过键盘或悬停访问。

迁移、规则及测试说明见 [联赛与经营规则](COMPETITION_RULES.md)。

行动结果和交流选人使用独立弹窗，显示已经执行的实际变化或明确出访费用。字体与按钮尺寸分别调整，手机首页状态标签至少12px，人物姓名和主要正文更大，导航增加短文字标签。名册每页六人，保留搜索、筛选与翻页；长档案局部滚动。

校长行动仍按教学、校园、人才、财政分类，效果和费用集中展示。减少介绍口号，保留决策所需信息。考前“按均分选五班”等快捷预设减少重复操作。
