# 校园界面更新 · 2026-11-06

让玩家知道学校正在发生什么、自己可以做什么，以及下一周值得期待什么。

## 页面分工

| 地点 | 默认呈现 | 详细信息入口 |
| --- | --- | --- |
| 校园 | 晨景、强校进程、行动力、三项动态建议、四项核心校情 | 全部校情、校务手记、秘书建议 |
| 实力版图 | 全市地块与选中学校，保留联考入口 | 学校详情、联考预约 |
| 组织人事 | 校级班子 | 处室／年级分区、教师／待任／市场标签，名册每页十二人 |
| 学生学业 | 一个年级的六个班级 | 年级切换、全部班级、全校分页名册、班级和个人档案 |
| 学校政策 | 一个制度分类的现行政策 | 展开单项比较选项；稳定度公式单独展开 |
| 财务资产 | 校园建设图与选中设施 | 经费分配、收支账本，降标变卖另行展开 |
| 校长行动 | 一个方向的行动卡片 | 教学、学生校园、人才资源、财政、校长专属 |

建议沿用既有秘书评估逻辑，直接进入对应行动分类。强校之路使用实时排名及与前一名的实力差，不添加隐藏奖励或改变胜负规则。

## 代码职责

- `index.html`：场景、导航、内容容器与游玩指南。
- `game-ui.css`：校园视觉、响应式、分区与交互状态，加载于历史样式之后。
- `game-ui.js`：仅负责显示、分类、分页、展开、焦点管理和经营指引，临时筛选不写入存档。
- `game.js`：继续持有游戏状态、数值计算、成本、奖励、事件与存档；完成渲染后通知界面层更新。
- 原事件库和调度模块保持不变。

## 验证

运行 `node --check game.js`、`node --check game-ui.js`、`node tools/ui-smoke.cjs`。

浏览器回归需要 Node 22+、Windows Chrome 默认安装路径和访问公开 GitHub 原版文件的网络权限。可提前把原版 `index.html`、`game.js` 放到 `tools/legacy/` 避免网络请求。使用系统临时目录中的独立 Chrome 档案，不读取玩家浏览器存档。截图和检查记录输出到 `docs/ui-review/`。

覆盖七个页面在 375、768、1024、1440 像素下的溢出与导航检查、分类和分页、政策展开、设施和预算交互、行动扣费、旧存档、每周三项简报、结果读档，以及高考期间处理简报后继续推进。

移动端时间推进固定在底部，七个主导航保留文字；提供游玩指南、可见焦点、弹窗焦点约束和减少动态效果支持。
