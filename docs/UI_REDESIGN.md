# 紧凑界面 · 2026-11-06

首页保留校园、行动力、积分目标、全部十二项状态和可展开校务手记。删去重复口号、页面解释与重复指标。资金、时间推进和导航固定可用。

学校联赛使用八行积分榜；人事按职责切换，教师按年级、班级列名；学生按年级查看五班；政策按分类逐项展开；财务分为建设、预算、账本；校长行动按目的分类。各分页面采用单屏优先布局，长名册和档案在局部区域查看。

`compact-ui.css` 最后加载，统一覆盖历史移动端排版。所有核心状态始终显示。固定头尾为触摸操作预留空间，数值说明仍可通过键盘或悬停访问。
